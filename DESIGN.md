# Design

## Intent

Mode: EXPERIENCE (portfolio). The work owns the first viewport. The interface stays out of the way.

Use scene: an engineer or hiring manager skims for ten seconds on a laptop, then reads one project closely. Dark by default for dev audiences, light available.

## Rules

- One accent (amber). Everything else is neutral. No gradients, no glow, no glass.
- Show the real artifact of each project: diagram, boot log, benchmark. Never a card that describes one.
- Display and body use Instrument Sans. Mono is for data, code and labels only.
- One authored motion: the hero diagram draws itself once. Reduced motion disables it.
- Cards are not decoration. The project index is a list; a row opens to its artifact.
- Content claims must come from the repos. No invented metrics.

## Tells to avoid

Gradient text, eyebrow chips, numbered section chips, stat strips, three-up card grids, icon tiles, particle or spotlight backgrounds, pulsing dots.
